# Attribution

retribution-pc is built from the [Vencord](https://github.com/Vendicated/Vencord) and [Revenge](https://github.com/revenge-mod) ecosystems and rebadged as a standalone desktop component of the Retribution project.

## Original work

- **Vencord** — a cross-platform client mod for Discord, created by [Vendicated](https://github.com/Vendicated) and the Vencord contributors.
- **Revenge** — the mobile client-mod project that Retribution is based on, created by the Revenge team and contributors.
